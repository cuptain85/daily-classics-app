# Daily Classics Privacy Policy

**Effective date: November 26, 2026**

Daily Classics is an Android game collection published from this repository.

## Information the app handles

The current version stores game progress and preferences on the device. This can include puzzle entries, crossword letters, game state, and the Solitaire Draw 1 / Draw 3 preference. This information is stored in the app's local Android preferences.

The current app does not require an account and does not include advertising, analytics, third-party tracking, cloud synchronization, or an in-app data collection service. The app does not request the Android Internet permission.

Android's own backup and restore features may handle app data according to the device's operating-system settings. This behavior is controlled by Android and the device owner.

## Sharing

The current app does not transmit game progress to the developer or to a server. If you choose to share information in a public issue, review it first and do not post personal or sensitive information.

## Children's privacy

The current version does not knowingly collect personal information from children or other users. It is an offline game app and does not include user accounts or social features.

## Data retention and deletion

Game data remains in the app's local storage until it is cleared by the user, removed through Android app settings, or removed when the app is uninstalled. Android device backup behavior may affect whether data can be restored.

## Changes to this policy

This policy describes the current app build. If future versions add analytics, advertising, accounts, online services, or other data handling, this policy and the app's disclosures must be updated before those features are released.

## Contact

For privacy questions, open an issue at [the Daily Classics GitHub repository](https://github.com/cuptain85/daily-classics-app/issues). Do not post private information in a public issue.
