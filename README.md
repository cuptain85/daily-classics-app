# Daily Classics

An Android game collection with four games:
- Daily Sudoku
- Daily Crossword
- Partnership Spades
- Klondike Solitaire

The current commit is the native Android starter app and approved home-screen direction. Game screens and game engines will be added in follow-up milestones.

## Open in Android Studio
1. Open Android Studio.
2. Choose **Open** and select this repository folder.
3. Allow Gradle sync to finish.
4. Run the **app** configuration on an Android emulator or device.

Requirements: Android Studio with JDK 17 support and Android SDK 35.

## Current starter features
- Native Kotlin + Jetpack Compose.
- Bright blue-and-green home screen.
- Four large game tiles.
- Separate calendar shortcut on each tile.
- Settings shortcut.
- Responsive scrolling layout.
